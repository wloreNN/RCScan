# RCScan 1.0.0

RCScan 1.0.0 is an evidence-driven vulnerability assessment scanner built in Python for explicitly authorized security testing.

## Key capabilities

- Explicit authorization and scope enforcement before any connection
- Asynchronous TCP connect scanning, host discovery, and service fingerprinting
- Conservative CVE correlation that reports potential applicability, not confirmed exploitation
- Bounded same-origin web discovery and passive web checks
- Active indicators for SQL injection, reflected XSS, and path traversal or local-file disclosure
- Static origin-bound headers and cookies, with polite per-origin throttling
- JSON, standalone HTML, and SARIF 2.1.0 reports with centralized secret redaction

## Safety model

Every target must match the declared scope. `--confirm-authorized` records the operator's attestation and does not grant permission. Loopback and public targets require their own opt-ins. Request, port, and concurrency limits stay in force. Credentials do not cross origins. RCScan does not perform credential attacks, brute force, WAF evasion, proxy rotation, exploitation, or post-exploitation.

## Reports

JSON is for automation. HTML is a standalone assessment deliverable. SARIF 2.1.0 is for code-scanning style ingestion. All three formats come from one canonical report.

## Platform

RCScan 1.0.0 requires Python 3.12 or newer. The v1.0 release gate passed on Ubuntu, Windows, and macOS using Python 3.12, including package validation.

## Testing baseline

729 tests pass locally. Ruff and mypy pass. Wheel and sdist builds pass Twine validation, and a clean wheel install runs outside the source tree.

## Known limitations

- IPv4 only; IPv6 targets are rejected
- No browser or JavaScript execution for crawling or XSS confirmation
- Static authentication only; no automatic login or re-authentication
- A small reviewed set of active web checks, using GET
- CVE correlation does not establish exploitability
- No WAF bypass, proxy rotation, distributed scanning, or post-exploitation

## Installation

RCScan is not published on PyPI.

From a built wheel:

```text
pip install path/to/rcscan-1.0.0-py3-none-any.whl
```

From a source checkout, using Python 3.12:

```text
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
```

Linux and macOS:

```bash
source .venv/bin/activate
python -m pip install -e ".[dev]"
```
